# SwarmForge handoffs

These JSON files are historical artifacts from the six-stage SwarmForge
pipeline. The `in_process` directory is retained so the multi-agent build trail
is auditable; it does **not** indicate that current work is blocked or
unfinished. The current release status is in [`QUALITY_REPORT.md`](../../QUALITY_REPORT.md).

Role prompts and the engineering constitution live one level up in
`.swarmforge/`.
